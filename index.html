How It Works

Three stages powered entirely by the Stack data structure

①

Tokenize

The input expression is split into tokens: numbers (including decimals), operators + − * / % ^, and parentheses.

②

Infix → Postfix

Using the Shunting-Yard algorithm and an operator stack, the infix expression is converted to Reverse Polish Notation (postfix).

③

Evaluate

A second stack evaluates the postfix expression: operands are pushed, operators pop two values, compute, and push the result.

Stack Interface

class Stack {
  push(item)   // Add to top
  pop()        // Remove & return top
  peek()       // View top without removing
  isEmpty()    // Check if empty
  size()       // Number of elements
  toArray()    // Snapshot for visualization
}

Shunting-Yard Conversion Rules

  • Operand — Append directly to the postfix output.
  • ( — Push onto the operator stack.
  • ) — Pop operators to output until ( is found; discard (.
  • Operator — While top has higher precedence, or equal precedence and left-associative, pop to output. Then push current operator.
  • End — Pop all remaining operators to the output.

Postfix Evaluation Rules

  • Operand — Push onto the evaluation stack.
  • Operator — Pop second operand, then first operand. Compute first ⊗ second and push the result.
  • End — The single remaining value on the stack is the answer.

About MathStack

MathStack is a college Data Structures & Algorithms project that demonstrates the practical use of the Stack ADT for mathematical expression evaluation.

Instead of relying on built-in language evaluation (eval()), every calculation is performed by first converting the infix expression to postfix notation using the Shunting-Yard algorithm, then evaluating the postfix expression — both stages driven exclusively by stack operations.
